# آدرس سرور L2TP و SSTP

سرور می تواند دامنه، آدرس IPv4 یا آدرس IPv6 باشد. دامنه هایی که فقط رکورد AAAA دارند نیز پشتیبانی می شوند. برای رسیدن مستقیم به سرور IPv6، اینترنت روتر باید مسیر IPv6 فعال داشته باشد؛ وارد کردن یک دامنه به تنهایی چنین مسیری ایجاد نمی کند.

در لینک اشتراک گذاری، آدرس IPv6 داخل براکت نوشته می شود:

```text
l2tp://user:password@[2001:db8::1]:1701?ipsec=0
sstp://user:password@[2001:db8::1]:443
```

برای سرورهای IPv6، انتقال محلی جداگانه ای بسته های TCP یا UDP ابزار اتصال را به سرور می رساند. این پردازش فقط روی لوپ بک گوش می دهد و همراه همان تونل متوقف می شود. تنظیم مسیریابی اصلی روتر تغییر نمی کند. در L2TP/IPsec، مذاکره IPsec با آدرس واقعی IPv6 سرور انجام می شود.

آدرس IPv6 سرور با IPv6 داخل تونل فرق دارد. گزینه `ipv6=1` در لینک، مذاکره IPv6 داخل PPP را برای سرورهایی که از آن پشتیبانی می کنند فعال می کند. حالت پیش فرض خاموش است تا سرورهای فاقد IPv6CP دچار قطع اتصال نشوند.
